# PinTodo · 常驻桌面待办清单

一个零重度框架依赖、启动迅速、界面精致的常驻桌面待办清单（基于 Tauri 2 + SolidJS + Rust）：
- **程序本体**：构建产物 `src-tauri/target/release/todo.exe`（单文件，无需安装）
- **桌面快捷方式**：双击桌面上的 **PinTodo** 即可启动（单实例，再次启动会直接唤起已有窗口）
- **开机自启**：右上角 `···` 菜单 → 勾选「开机自启」（写入注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\PinTodo`）

---

## 核心操作

| 操作 | 方式 |
|---|---|
| 添加待办 | 顶部输入框输入，**回车**保存；支持**粘贴多行文本**自动批量拆分为多条待办 |
| 智能录入语法 | `!1`/`!2`/`!3`（高/中/低重要度）、`#标签`、`@清单`、`今天18:00`/`明天`/`周五`/`下周一`/`月底`/`每天8:30`/`每周三18点` |
| 排序规则 | 组内自动按：**收藏打星（★）→ 重要程度（`!1` > `!2` > `!3`）→ 截止时间越早越前 → 当天已完成沉底**（填写进度反馈不打乱排序） |
| 进度反馈与历程时间轴 | 点击任务右侧 **进度波形图标**（或右键 → 进度反馈 / 点击行内进度胶囊）打开**专门的进度打卡弹窗**：每次打卡自动记录时间戳生成时间轴过程（最新进展高亮），支持单条删除或清空历程；行内胶囊展示最新一条进度及打卡次数角标 |
| 删除事项 | 点击行尾 **×** 或右键 →「删除」会弹出**确认框**（取消 / 删除），防止误删；确认后仍可在底部提示条点「撤销」找回 |
| 完成 / 次日自动隐藏 | 点击左侧 **圆圈**（选中时也可按空格/回车）。当天完成的任务当日仍在底部保留（划线），**次日起自动从清单隐藏**并归入历史 |
| 历史完成日历与清单导出 | 顶部切换至 **历史** 分段栏，月历上带绿色角标的日期为有完成记录的日期，点任意日期查看当天全部完成清单；支持日历头部或页脚 **导出清单**：可自由导出【所选单日完成清单 / 当月完成月报 / 全部历史完成汇总】，格式支持 Markdown、CSV 表格（Excel 打开不乱码）和纯文本 |
| 展开 / 编辑描述 | **单击**任务选中 → **再单击**（或点 📄 图标）展开描述区，失焦/600ms 自动保存，**Esc** 保存并收起 |
| 编辑标题与改期 | **双击**任务标题编辑；**点击任务上的时间芯片**（如 `今天 18:00`）可快速推迟或自定义日期 |
| 时间分类折叠分组 | 清单视图按时间自动分组：**今天**（含逾期）、**本周**、**本月**、**持续**（无截止/更远期）；点击分组标题可**折叠/展开**，折叠偏好自动记忆；「今天」组即使为空也常驻展示，当天完成的任务保留在原分组沉底；页脚统计只计当前可见项，与列表行数一致 |
| 挂起任务（暂缓处理） | 右键任务 →「**挂起（暂缓处理）**」：任务收进清单末尾的「**挂起**」折叠分组、文字置灰；挂起任务**不计入待办数、不触发到期提醒**，胶囊计数也跳过；点击行内「已挂起」标记或右键「取消挂起」即可恢复 |
| 事项标签管理 | 悬停任务行点击「+ 标签」或右侧**标签图标**，或**右键 → 设置标签…** 打开标签弹窗：输入回车即添加、点 × 移除，还可一键勾选其他任务用过的标签；点击任务上的标签可按该标签筛选 |
| 视图切换 | 第二层分段栏：**清单**（含时间分组折叠）· **随手记** · **历史** |
| 随手记转待办 | 在 **随手记** 里记完要点后，点右下角「**转为待办**」（选中几行就只转选中部分，未选则全部拆转） |
| 侧边小精灵胶囊 | 拖到屏幕左/右边缘松手，或点标题栏 **—** / 按 **Esc**，窗口收进侧边变为半嵌入的呆萌小精灵胶囊；**单击一次直接滑出完整待办窗口**；拖动可自由挪到屏幕任意位置或重吸回侧边 |
| 挂起态（Win+D） | 按 **Win+D** 显示桌面时自动进入**挂起态**：胶囊**留在桌面上闭眼睡觉（Zzz）**、保持置顶不消失；**单击胶囊立即唤醒**并恢复完整窗口；切到其他窗口时胶囊自动苏醒（保持贴片形态） |
| 关闭按钮 | 点 **✕** 弹出选项：**收进侧边栏**（保留运行）或 **退出 PinTodo** |
| 全局热键 | **Ctrl + Alt + Space**：显隐 / 收进侧边；**Ctrl + Alt + A**：在任意界面弹出快速添加窗 |
| 撤销与搜索 | 列表区 **Ctrl + Z** 撤销操作（输入框内保留原生文本撤销）；按 **`/`** 搜索任务、描述与标签；按 **`?`** 打开快捷键/语法指南 |

## 数据与备份

数据目录：`%APPDATA%\PinTodo\`（资源管理器地址栏输入 `%APPDATA%` 即可直达）

| 文件 / 目录 | 说明 |
|---|---|
| `tasks.json` | 全部待办与历史完成数据（150ms 防抖原子写入，兼容旧版结构） |
| `scratchpad.txt` | 随手记内容（自动保存纯文本） |
| `settings.json` | 窗口位置尺寸、主题（跟随系统/浅色/深色）、置顶、清单与停靠边设置 |
| `backup/` | 每次启动自动滚动保留最近 7 份 `tasks-*.json` 备份 |

另可在 `···` 菜单中随时 **导出 / 导入 JSON 或 `todo.txt`**。
